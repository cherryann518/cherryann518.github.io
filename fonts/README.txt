Satoshi, the text font across the site, is not in this folder on purpose.

  Satoshi by Indian Type Foundry (https://www.fontshare.com/fonts/satoshi) is free for
  personal and commercial use, but its licence does not allow uploading the font files
  to a public server, which a public GitHub repository is. So the first line of
  styles.css loads it from Fontshare's own servers.

m3x6, the pixel font for the headline and titles.

  m3x6.ttf           m3x6 by Daniel Linssen (https://managore.itch.io/m3x6). Unchanged.
                     His page says it is free to use with attribution, so keep this credit.
                     It is sharp at 16px and whole multiples of it; the site uses 32, 48 and 64.
  pixel-marks.woff   Five marks m3x6 does not have (curly apostrophes, dashes, ellipsis),
                     drawn for this site on the same grid.

Latin Modern fonts, used only by the resume page (work/resume.html).

Originals: https://www.gust.org.pl/projects/e-foundry/latin-modern
           https://www.gust.org.pl/projects/e-foundry/lm-math
