Project

GAIA Tool-Using Agent

An agent that answers GAIA eval questions by writing code that calls its own tools. I built it during the Hugging Face Agents Course.

What it does

The agent is a smolagents CodeAgent. I gave it tools for:

  • web and Wikipedia search
  • YouTube transcripts
  • attached files: PDFs, spreadsheets, images through OCR, and audio through speech-to-text

Getting through a full run

Three additions kept a run going and its answers scoreable:

  • a fallback from Hugging Face models to Groq
  • answer caching, so a run can resume after the Space restarts
  • exact-match answer normalization for the scoring API
