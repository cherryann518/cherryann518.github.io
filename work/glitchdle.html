Playground

Glitchdle

A five-letter word game where the colors lie. After each guess the tiles change color to tell you how close you are, except that in every guess one tile shows the wrong color.

Play it

Three modes

The modes differ in what happens to the wrong tile afterwards.

  • Flicker: 6 guesses. The wrong tile is corrected right after your next guess, so only your newest row can’t be trusted.
  • Scanner: 6 guesses. The wrong tile stays, and you get 3 scans per game. Scan an honest tile and it gets a cyan mark. Scan the wrong one and it flips to its real color, which clears the whole row.
  • Corrupt: 8 guesses. The wrong tile stays and there are no scans.

The limits differ for a reason. A careful player solves Flicker and Scanner within 6 guesses about 97% of the time, close to a game with no lies at all. In Corrupt the lies never get cleared up, and the same player only makes it within 6 about 93% of the time, so it gets 8.

Daily and practice

Daily is one puzzle per mode per day. Everyone gets the same word and the same wrong tiles. Both are worked out from the date, so no server is involved. When you finish, you can copy your result as an emoji grid, where a purple square is a tile that lied to you.

Practice is random words, as many games as you like.

How it’s put together

  • No build step and no dependencies. It is a plain static site in HTML, CSS and JavaScript modules.
  • Each kind of lie is its own small class, so adding a mode means one class and one entry in a list.
  • Every letter is drawn from a 5x7 bitmap. A tile is 35 individual pixels, which is how it scrambles into static and locks back into a letter.
  • Green is solid, yellow has a dithered edge and gray is a dark block, so the three can be told apart without relying on hue.
  • The game picks from 1,310 hand-picked answers and accepts 6,576 words as guesses.
