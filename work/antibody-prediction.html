Project

Antibody Level Prediction

A model that predicts a person’s antibody level from their vaccination and infection history. I built it in R with data.table for a Kaggle competition.

Features

The data counts days between each event and the blood sample. A negative count means the event came after the sample, so it cannot have affected the antibody level. Those are recoded as not yet: no third dose yet, no prior infection yet.

The cleaned features are the most recent dose and how long ago it was, the vaccine brand, prior infection, and symptom severity.

Covariate screening

Each sample also comes with about 100 CovVar covariates. I kept only the ones whose correlation with log antibody level was above 0.1 in absolute value. The log is there because antibody levels are skewed.

Validation

The same clinical profile appears many times in the training data with only age and sex changed, so random row folds would put near-identical rows on both sides. The five folds hold out whole profiles instead.

Three linear models are compared by mean absolute error on the original scale, against a null model that always predicts one constant.

Profile lookup

When a test row has exactly the same clinical profile as rows in training, the prediction is the training average for that profile rather than the regression estimate.
